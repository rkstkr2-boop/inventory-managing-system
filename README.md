# Mobile Shop Inventory

Open `index.html` in Chrome or Edge to start. Works on phones too.

| Role | Username | Password |
|------|----------|----------|
| Managing Director | director | director123 |
| Inventory Manager | manager | manager123 |
| Employee | employee | employee123 |

Change these under Users after the first login. Use Users > Clear demo / all data to remove the sample products.

## Files
- index.html, js/login.js, css/login.css - login page
- app.html, js/app.js - main screen and menu
- js/storage.js - saved data
- js/categories.js - product types and the details asked for each
- js/auth.js - roles and permissions
- js/services.js - stock rules (a sale reduces stock, cancelling restores it, every change is logged)
- js/ui.js - shared helpers
- js/views/ - Dashboard, Stock, Sales, Stock Log, Reports, Users
- css/style.css - look and feel
